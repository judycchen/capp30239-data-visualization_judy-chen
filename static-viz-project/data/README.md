# Data files

Put these two files in this folder before running the notebook:

- [CPES](https://www.icpsr.umich.edu/web/ICPSR/studies/20240): download the DS1 combined file in Stata format, named `20240-0001-Data.dta`.
- [NSDUH 2024](https://www.samhsa.gov/data/data-we-collect/nsduh-national-survey-drug-use-and-health/datafiles/2024): download the delimited-file ZIP containing `NSDUH_2024_Tab.txt` and name it `nsduh2024.zip`. It does not need to be unzipped.

The raw files stay local because they are large and CPES has redistribution restrictions. They are excluded from Git; this folder only shares these instructions.
