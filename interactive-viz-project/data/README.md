# Data files

This project reuses the static project's CPES 2001–2003 and NSDUH 2024 datasets.
See [the existing download instructions](../../static-viz-project/data/README.md).

The existing local files are at:

- `../../static-viz-project/data/20240-0001-Data.dta`
- `../../static-viz-project/data/nsduh2024.zip`

Paths above are relative to this data folder. From the interactive project root, use `../static-viz-project/data/`.
No duplicate download is needed when those files are already present. Raw respondent-level data stays local and is excluded from Git. Any data published for the interactive website should be reviewed for source permissions and disclosure requirements first.
