# Local survey data

Keep respondent-level files in this ignored directory. Do not upload them to this repository.

Expected local filenames:

- `20240-0001-Data.dta`: the complete CPES combined public-use file (DS1, ICPSR 20240).
- `nsduh2024.zip`: the NSDUH 2024 delimited-file archive containing `NSDUH_2024_Tab.txt`.
  The downloaded archive can be renamed locally to this filename without extracting it.

[CPES access and documentation](https://www.icpsr.umich.edu/web/ICPSR/studies/20240)
and [NSDUH 2024 downloads](https://www.samhsa.gov/data/data-we-collect/nsduh-national-survey-drug-use-and-health/datafiles/2024).

CPES access is available through ICPSR; its supplied terms restrict redistribution.
Original source files are also larger than the course's 100 MB file threshold when uncompressed.
The repository contains code and aggregate figures, with local acquisition instructions.
